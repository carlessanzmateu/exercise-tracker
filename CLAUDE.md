Restricciones críticas (recordatorio rápido — el detalle está en `Requirements.md`):

- PWA pura, sin backend, persistencia en IndexedDB.
- **TDD innegociable**: ningún código de producción sin un test previo que falle.
- React + Vite + TypeScript. Vitest + React Testing Library + fake-indexeddb para tests.
- UI en español, métrico, modo claro/oscuro automático.
